# SUZY//WORLD Research Index

This directory is the public design journal for SUZY//WORLD.

## How to use this with AI

When asking an AI to research or continue this project, point it to:

```text
AI-CONTEXT.md
docs/research/README.md
```

Then have it read the relevant dated note.

A useful prompt is:

> Read `AI-CONTEXT.md` and `docs/research/README.md` in `suzyeaston/suzy-world`, then use the dated research notes to reconstruct the project state before suggesting changes.

## Naming convention

Research notes use:

```text
YYYY-MM-DD-topic.md
```

The date is the date the note was written or reconstructed.

Each note should include metadata near the top:

```text
date
source period
project
document type
status
keywords
related repositories
```

This keeps the journal easy to search chronologically and semantically.
